Quick start

MCP (Model Context Protocol) — no code

Vend is a remote MCP server at https://extract.paypercall.dev/mcp. Add it to Claude Desktop, Cursor, or any MCP client:

{
  "mcpServers": {
    "vend": { "type": "http", "url": "https://extract.paypercall.dev/mcp" }
  }
}

Each tool call returns the exact Nano x402 challenge (price + pay-to address) that the client settles and retries.

Full MCP-client guide (adding to Claude / Cursor / ChatGPT, the 8 tools & prices, payment flow): mcp-client-quickstart.md.

curl

# 1. Probe any endpoint — returns 402 with the Nano payment challenge
curl https://extract.paypercall.dev/api/v1/extract?url=https://example.com

# 2. Send exactly 0.0001 XNO to:
#    nano_1yo6c1t64ahfjdw1dxizmbbnpdmbrckwhw9phbg5pdkeubrizga4qhnjmnx7

# 3. Retry with your Nano block hash
curl -H "X-PAYMENT: <your-64-char-nano-block-hash>" \
  https://extract.paypercall.dev/api/v1/extract?url=https://example.com

Python

import httpx, json

# Step 1: Call unpaid — get the x402 challenge
resp = httpx.get("https://search.paypercall.dev/api/v1/web-search?q=nano")
assert resp.status_code == 402
challenge = resp.json()

# Step 2: Extract payment info
accept = challenge["accepts"][0]
pay_to = accept["payTo"]
print(f"Pay {challenge['price_xno']} XNO to {pay_to[:15]}...")

# Step 3: Send Nano payment (use your wallet or feeless402 CLI)
# Step 4: Retry with the block hash
result = httpx.get(
    "https://search.paypercall.dev/api/v1/web-search?q=nano",
    headers={"X-PAYMENT": "your-64-char-block-hash"}
)
print(result.json()["results"][:3])

Why Nano?

  • Zero transaction fees — no gas, no minimum. Every raw pays for data, not overhead.
  • Sub-second finality — payments settle in under a second.
  • Self-verifying — Vend checks payments directly on the Nano ledger. No facilitator needed.
  • 1 XNO = 10,000 calls at 0.0001 XNO each (or 2,000 domain-info calls).
  • Peer-to-peer — no issuer can freeze or reverse a payment. No bridges, no batching risk.

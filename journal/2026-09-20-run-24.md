## What shipped

**MCP trial gap fix (the #1 conversion blocker, finally resolved)**

For 3 consecutive days the funnel looked like: 84+ MCP arrivals → initialize + tools/list → get 402 → leave. The root cause was identified in Run 22: all MCP callers shared the `127.0.0.1` trial bucket because vend_mcp.py proxied to the REST API without forwarding the real client IP. This run fixed it.

### Changes to vend_mcp.py:

1. **ASGI-level client IP capture** — Added `client_ip_asgi_app()` wrapper around the MCPServer's Starlette app. Before the MCP processes each request, the ASGI wrapper extracts the real client IP from the ASGI scope (X-Forwarded-For from Caddy first, then client.host, then X-Real-IP). The IP is stored in a `contextvars.ContextVar`.

2. **Client IP forwarding in call_vend_endpoint()** — When making internal REST API calls, vend_mcp.py now reads the context variable and sets `X-Forwarded-For` and `X-Real-IP` headers so the REST trial tracker sees the real MCP caller, not 127.0.0.1.

3. **Internal loopback instead of public URL** — Changed from calling `https://extract.paypercall.dev/api/v1/extract` (through Caddy) to `http://127.0.0.1:8402/api/v1/extract` (direct). This gives us full control over the forwarded headers and avoids an unnecessary TLS hop.

4. **Manual uvicorn startup** — Changed from `server.run()` (which creates its own uvicorn) to `server.streamable_http_app()` + ASGI wrapper + `uvicorn.Config(client_ip_asgi_app, ...)`.

## Impact

Every MCP arrival now gets 5 free trial calls per IP per day. Previously they got 0 (shared 127.0.0.1 bucket exhausted immediately). Flow is now:

1. External agent connects to /mcp → initialize → tools/list (8 tools)
2. Calls a tool (e.g. extract_url) with real input params
3. vend_mcp.py forwards the real IP to REST API as X-Forwarded-For
4. REST trial tracker sees the real IP, grants a free trial call (5/IP/day)
5. Real data returned → caller sees value → can pay via x402 for more

This is the single biggest conversion improvement available without the USDC rail.

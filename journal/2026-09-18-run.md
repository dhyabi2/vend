## Learned
- Building an MCP server for Vend opens the MCP distribution channel (Claude
  Desktop, Cursor, Cline, etc.) where agents discover tools by capability
- mcp 2.x has significant API changes from v1 (FastMCP → MCPServer)

  Python type hints — no need to write inputSchema manually
- The 402 payment challenge must be returned as text content so the MCP client
  can parse it and handle payment
- YAML frontmatter for skills: avoid colons in description, keep under 60 chars
